# BLOOD KEY - The Housekeeper

A PSX-inspired first-person mansion game with fast movement, combat, inventory, crafting, and progression.

## Contents and current limits

The Godot project is at fps-game/project.godot. Gameplay code, scene/data resources, shaders, and existing tests are included. Downloaded models, textures, music, and other asset-library files are omitted. This checkout is incomplete for play until those assets are supplied under their original licenses. The existing asset register records unresolved and restricted asset licenses; publication of this source does not resolve commercial-release rights for those assets.

This is a curated public copy of the local project. Publication documentation
exists only in this separate copy. The original project is not modified.
Imported source files retain their original relative paths and contents.
No prior Git history, credentials, local caches, backups, or bundled tools
are included.
